# Laboratórny test K49E

## Cieľ
Zistiť nulový bod, šum, drift, citlivosť, linearitu, opakovateľnosť a teplotnú závislosť K49E.

## Test 1 – nulový bod
1. Senzor upevniť do nemagnetickej mechaniky.
2. Odstrániť magnetické predmety z okolia.
3. Nechať teplotne ustáliť.
4. Zaznamenávať minimálne 10 minút.
5. Vypočítať priemer, min, max, std a peak-to-peak.

## Test 2 – šum
Po ustálení zaznamenať aspoň 60 s a vypočítať mean, median, std, RMS a peak-to-peak.

## Test 3 – drift
Zaznamenávať 1–2 hodiny bez pohybu spolu s teplotou.

## Test 4 – známy magnet
Použiť rovnaký magnet, vzdialenosť a orientáciu. Opakovať pre viac vzdialeností.

## Test 5 – porovnanie kusov
Senzory označiť `K49E-01`, `K49E-02`, ... a všetky testovať za rovnakých podmienok.

Výsledkom má byť individuálny kalibračný profil každého senzora.

Poznámka: závery o použiteľnosti K49E robiť až z meraní, nie iba z datasheetu.
